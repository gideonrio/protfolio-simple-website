# 🌐 Personal Portfolio Website

A personal portfolio website developed using **HTML5 and CSS3** to showcase my profile, interests, projects, and contact information. The website consists of two pages: Home and Contact, with a simple and clean user interface.

## 📄 Pages & Features

### 1. Home Page
- Displays my name and professional role.
- Includes my personal introduction and background.
- Showcases my interests and technical skills.
- Highlights my projects with brief descriptions.
- Provides links to my social media profiles.

### 2. Contact Page
- Displays my contact information.
- Includes a contact form for visitors to get in touch.

## 🛠️ Technologies Used

- **HTML5** – Used to structure the web pages.
- **CSS3** – Used for styling, layouts, and design.
- **Google Fonts** – Used to enhance typography.


## 🎯 Project Objective

The main objective of this project is to practise HTML and CSS concepts and build a personal portfolio website to showcase my profile and web development skills.
